# Protos

Protos is an experimental prototype-based programming language built around
objects, slots, delegation, messages, contexts, closures, Futures, and Actors.

The website is being built from canonical project sources. Language semantics
remain authoritative in the
[Protos repository](https://github.com/guillermomolina/protos).
