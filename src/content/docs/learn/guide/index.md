# Programming guide

The canonical Protos Programming Guide explains **how to think about and use**
the language. It is deliberately non-normative: if guide prose and the
specification disagree, the specification wins.

The current locked source revision contains this progression:

1. Bindings, contexts, and object state
2. Objects, delegation, and composition
3. Closures, methods, and receivers
4. Control flow through ordinary protocols
5. Values, identity, equality, and collections
6. Modules and imports
7. Errors, handlers, `ensure`, and resource lifetime
8. Futures and structured concurrency
9. Isolated parallel execution
10. Actors, ActorRefs, and Actor Groups
11. Process, I/O, Filesystems, and Authority

The guide, tutorials, and examples serve different purposes:

- **Guide:** concepts and mental models.
- **Tutorials:** small progressive executable programs.
- **Examples:** task-oriented answers to “how do I do X?”

This page is the stable website entry point for the guide. Full chapter
rendering from the exact locked canonical source will be integrated without
turning this repository into an independently maintained copy.
