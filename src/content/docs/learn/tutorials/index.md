# Tutorials

The canonical tutorials teach Protos progressively using small `.protos`
programs. They are explanatory material; the specification remains normative.

The current locked source revision progresses through:

1. Values and slots
2. Objects
3. Closures
4. Control flow
5. Collections
6. Path values
7. Call arguments
8. Language interactions
9. Futures
10. Actors
11. Actor groups
12. System resources

The tutorial sources are designed to stay executable rather than becoming
pseudo-code documentation. Print-dependent lessons are exercised through CLI
regression coverage where applicable.

Start with [Getting started](/learn/getting-started/) if you have not yet built
the reference implementation.
