# Try Protos

The [official first-run instructions](/docs/live/?family=guide&path=docs/guide/00-try-protos.md)
are maintained in `guillermomolina/protos/main` and displayed directly by this
website's live documentation reader. The [first-program walkthrough](/docs/live/?family=guide&path=docs/guide/first-program.md)
is also sourced from current `main`.

For a current Linux installation, follow the official Native Image installer in
the canonical first-run guide. The installed native runtime requires no JDK or
Maven. Other distribution types and requirements are documented at the same
live source; do not use historical static release instructions.

The website does not install software or independently publish a release.
Published binaries and checksums come from
[GitHub Releases](https://github.com/guillermomolina/protos/releases).
