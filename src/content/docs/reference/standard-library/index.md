# Standard library

Protos keeps the language core and reusable library facilities conceptually
separate. This website consumes the Standard Library from the same exact
immutable Protos revision as the language reference, guide, tutorials, and
examples.

## API reference

[Browse the Standard Library API](/reference/standard-library/api/) for the
complete D067 mechanically observable importable `std:` module/top-level-slot
inventory.

The API pages are generated by the **Protos-owned documentation producer from
that same exact revision** and rendered from the neutral D064 JSON model.
Authored D062 `//!` / `///` documentation is shown when present. Missing prose is
shown explicitly rather than used to hide an observable module or slot.

Mechanical presence does **not** by itself imply support, stability,
compatibility, deprecation, or any other API-lifecycle promise.

## Exact source browser

[Browse the Standard Library source](/reference/standard-library/source/) to
inspect every `.protos` module in the locked `protos/lib` tree, including
physical `core/**` implementation sources that are deliberately not importable
as `std:core`.

The source browser preserves canonical family names, filenames, case, relative
paths, source bodies, and exact-SHA provenance. It remains implementation
presentation, not an independent semantic authority.

For observable language semantics, use the
[Language reference](/reference/language/).
