# Community

Protos is an experimental open-source programming-language project under active
development. Questions, ideas, bug reports, documentation improvements, code,
tests, benchmarks, tools, examples, and other contributions are welcome.

GitHub remains the live project coordination surface; this website does not
mirror issue state or design conversations.

## Questions, ideas, and design discussion

Use [GitHub Discussions](https://github.com/guillermomolina/protos/discussions)
for questions about using or understanding Protos, exploratory proposals,
design discussion, contributor help, introductions, and experiments.

If you are unsure whether something is ready to become tracked work, start in
Discussions.

## Bugs and actionable work

Use [GitHub Issues](https://github.com/guillermomolina/protos/issues) for
reproducible bugs, concrete documentation problems, and sufficiently scoped
actionable work.

A design idea does not need to become an Issue until there is a concrete problem
or outcome worth tracking.

## Contributing

Read the
[contribution guide](https://github.com/guillermomolina/protos/blob/3a92521fa492441070dd243cfb23c04cc370fc17/CONTRIBUTING.md)
before preparing a substantial change.

For external contributions, a branch or fork followed by a Pull Request is the
normal integration boundary. Changes should be narrow enough to review, respect
the normative specification, and report validation evidence appropriate to
their impact.

AI-assisted and fully AI-generated contributions are welcome under the same
correctness, review, provenance, specification, and validation standards as
other contributions. When AI materially shaped a contribution, the project asks
for a brief disclosure in the Pull Request.

## Security

Do **not** publish vulnerability details, credentials, private data, or working
exploit material in an ordinary public Issue or Discussion.

Follow the canonical
[Security Policy](https://github.com/guillermomolina/protos/blob/3a92521fa492441070dd243cfb23c04cc370fc17/SECURITY.md),
which directs reporters to GitHub's private vulnerability-reporting path when
available.

## Conduct and support

Project spaces follow the
[Code of Conduct](https://github.com/guillermomolina/protos/blob/3a92521fa492441070dd243cfb23c04cc370fc17/CODE_OF_CONDUCT.md).
Strong technical disagreement is welcome; personal attacks and harassment are
not.

Support is currently best-effort because Protos is experimental. The canonical
[Support guide](https://github.com/guillermomolina/protos/blob/3a92521fa492441070dd243cfb23c04cc370fc17/SUPPORT.md)
explains where to ask questions and what information makes them easier to
answer.
